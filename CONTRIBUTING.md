# Contributing

Thank you for helping improve Material Calculator. Please keep changes focused on quantity-estimation accuracy, clarity and accessibility.

## Workflow
1. Open an issue describing the problem or feature and expected behavior.
2. Fork the repository and create a descriptive feature branch.
3. Make small, documented changes; do not add tracking, hidden network calls or external dependencies without discussion.
4. Manually test all relevant calculators in a browser, both supported languages, invalid inputs and print output.
5. Open a pull request describing the formulas changed, worked numerical examples and test results. Note any checks you could not run.

## Formula bug reports
Include material type, each field value, expected quantity/cost with calculation, actual result, browser/OS and a screenshot if possible. Do not share client-sensitive project information.

## Style
Keep the application usable without accounts or a server. Avoid claiming estimates are final procurement quantities. Keep English and Bahasa Indonesia translations aligned. No personal or project-confidential data in examples.
